# HomeLAB Playground

A universal SwiftUI app for iPhone, iPad and Mac.

## Requirements

- Xcode 27.1 or later
- iOS 27, iPadOS 27 or macOS 27

## Build number

Every build's number is the repository's commit count (`git rev-list --count HEAD`), and the app shows it. A git hook keeps it current. Run this once after cloning:

```sh
Scripts/install-hooks.sh
```

## Third-party code

This app uses no third-party code.
